# AetherLens — Visual Discovery Engine

AetherLens is a high-resolution visual search application designed for fast, modern image discovery. Users can input search topics or select from popular category chips to browse a responsive grid of high-quality images.

## Key Design Decisions
1. **Dark Oceanic Palette:** I selected a deep slate (#0b0f17) and electric cyan (#00e5ff) theme to make visual content pop while maintaining a modern, high-contrast UI distinct from standard themes.
2. **Category Quick-Pick Chips:** Added a category row directly below the search bar so users can quickly explore popular topics with a single click.
3. **Dedicated Empty State & Status Meta Bar:** Included a clear initial state ("Search to see results") alongside a metadata header to give clear context before and after queries are run. #submission
